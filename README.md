# AI Daily Briefing

날짜별 완성된 AI 브리핑 Markdown을 보관하는 저장소입니다.

## 브리핑 파일

```text
briefing/YYYY/MM/YYYY-MM-DD.md
```

- 브리핑 확인·수집 대상은 위 경로의 날짜별 `.md` 파일입니다.
- 루트의 `README.md`는 저장소 안내이며 브리핑 수집 대상에 포함하지 않습니다.
- 날짜 기준 시간대는 `Asia/Seoul`입니다.
- 같은 날짜의 내용이 수정되면 같은 파일 경로를 갱신합니다. 이전 내용은 Git 기록에서 확인할 수 있습니다.
- 조사 프롬프트, 예약 작업 설정, 샘플 및 쓰기 시험 파일은 이 저장소에 보관하지 않습니다.

GitHub 파일 정리와 예약 작업 설정은 별개입니다. 기존 예약 작업이 삭제된 `prompts/daily-briefing.md`를 참조한다면 예약 작업의 지시문을 수정해야 합니다.
