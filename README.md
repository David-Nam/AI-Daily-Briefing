# AI Daily Briefing

AI 브리핑을 한국 시간 기준 날짜별 Markdown 파일로 누적 저장합니다.

## 구조

```text
briefing/YYYY/MM/YYYY-MM-DD.md   # 실제 브리핑
samples/2026-10-02.md            # 형식 예시, 실제 뉴스 아님
prompts/daily-briefing.md        # Work 반복 실행용 지시문
docs/setup.md                  # 설정 및 검증 안내
```

예: `briefing/2026/10/2026-10-03.md`

## 운영 원칙

- 날짜와 시간은 Asia/Seoul 기준입니다.
- 실제 브리핑은 원문 링크와 조사 범위를 포함합니다.
- 동일 날짜 파일이 있으면 덮어쓰지 않고 완료 여부를 확인합니다.
- GitHub에서 저장된 파일을 다시 읽어 확인한 후에만 성공으로 알립니다.
- 샘플은 마지막 성공 기록이나 뉴스 조사 기준에 포함하지 않습니다.
- 이전 예약 작업의 전체 프롬프트는 아직 확보하지 못했습니다. 기존 관심 분야와 출력 규칙을 새 지시문에 병합한 뒤 운영하세요.

## 현재 상태

2026-10-02: 저장소 읽기 접근 확인 및 기본 파일 준비. GitHub 연결 앱의 파일 생성은 403으로 실패하여 로컬 Git으로 초기화했습니다. 실제 뉴스 브리핑과 반복 예약은 아직 실행하지 않았습니다.
기본 시간은 확정되지 않았으며, 설정 안내에서는 매일 06:00 KST를 예시로 사용합니다.
