# Session 3 — AI for Firmware & Embedded Engineering

## 1. Agentic HIL: 실제 MCU를 test oracle로 연결

- **Firmware interpretation:** 코드 생성이 아닌 실제 보드 실행 결과로 완료를 판정한다.
- **Practical workflow:** Board/probe identity → cross-build → artifact 검증 → 승인된 flash → UART/CAN 수집 → pytest acceptance test → firmware hash와 로그 보관.
- **Useful tools / interfaces:** Agentic HIL MCP, OpenOCD, STM32CubeProgrammer CLI, ST-Link, pyOCD, pytest.
- **Benefits:** Compile-only agent의 검증 공백을 줄이고 반복 가능한 hardware regression을 만든다.
- **Limitations / risks:** Flash·reset은 장치에 영향을 준다. 허용된 probe, image, test bench를 고정하고 production 장비를 제외해야 한다.
- **Evidence / maturity:** 2026년 9월 시작된 community project; 자체 demo 존재, 산업 규모 검증 부족.
- **Sources:** [Agentic HIL](https://github.com/agentic-hil/agentic-hil?utm_source=chatgpt.com) · [Hackaday 프로젝트](https://hackaday.io/project/206788-agentic-hil?utm_source=chatgpt.com)

## 2. AutoEmbed: API 근거 기반 생성과 runtime 폐루프

- **Firmware interpretation:** LLM 기억 대신 실제 라이브러리 API를 추출하고 실행 결과로 검증한다.
- **Practical workflow:** 부품·핀맵 지정 → API 검색 → Arduino firmware 생성 → compile/fix → flash → runtime 검증.
- **Useful tools / interfaces:** AutoEmbed, Arduino CLI, USB serial, component library.
- **Benefits:** API hallucination을 줄이고 실보드까지 검증한다.
- **Limitations / risks:** 연구팀이 보고한 355개 task의 coding accuracy 95.7%, end-to-end 86.5%는 자체 평가다. STM32/ThreadX·독자 칩으로 일반화할 수 없다.
- **Evidence / maturity:** SenSys 2026 연구·공개 구현 / 독립 재현 필요.
- **Sources:** [AutoEmbed](https://github.com/AutoEmbed/AutoEmbed?utm_source=chatgpt.com)

## 3. OpenOCD MCP와 RTOS fault 진단

- **Firmware interpretation:** SWD register, ELF symbol, fault 상태를 구조화해 agent가 분석한다.
- **Practical workflow:** Read-only probe 검색·chip ID·PC/SP·fault register 수집 → ELF/DWARF 매칭 → 가설 생성 → 사람 검토 → 승인된 테스트 보드에서 검증.
- **Useful tools / interfaces:** openocd-mcp, embedded-debugger-mcp, GDB, probe-rs, SVD, UART/RTT.
- **Benefits:** 수동 register dump 복사를 줄이고 HardFault 분석을 재현 가능하게 만든다.
- **Limitations / risks:** Halt·memory write·option byte는 부작용이 있다. Register read도 clear-on-read일 수 있어 allowlist가 필요하다.
- **Evidence / maturity:** Community implementations / MCU별 실장비 검증 필요.
- **Sources:** [OpenOCD MCP](https://github.com/microhenrio/openocd-mcp?utm_source=chatgpt.com) · [Embedded Debugger MCP](https://github.com/adancurusul/embedded-debugger-mcp?utm_source=chatgpt.com)
