# Session 3 — AI for Firmware & Embedded Engineering

## 1. MCU debug agent: MCP + OpenOCD를 read-only와 destructive action으로 분리

**Firmware interpretation:** 공개된 openocd-mcp 및 embedded-debugger-mcp 프로젝트는 AI agent가 SWD/JTAG를 통해 register·memory를 읽고 flash·reset·fault diagnosis까지 수행할 수 있음을 보여준다. 다만 소규모 공개 프로젝트의 README는 광범위한 실기기 검증을 보증하지 않는다.

**Practical workflow:** read-only register/SVD inspection → ELF/DWARF symbol lookup → cross-build → binary hash 확인 → 보드 식별 → 승인 후 flash → UART/RTT log 수집 → 테스트 결과 평가. flash erase와 raw OpenOCD command는 별도 승인 경로를 둔다.

**Useful tools / interfaces:** OpenOCD, ST-Link, CMSIS-SVD, ELF/DWARF, probe-rs, MCP, UART/RTT.

**Benefits:** 디버깅 반복 작업 자동화와 실측 근거 기반 root-cause analysis가 가능하다.

**Limitations / risks:** openocd-mcp의 raw command 허용은 상위 write 제한을 우회할 수 있으므로 기본 deny를 권장한다. OTP/option-byte, mass erase, 잘못된 보드 flash는 사람 승인과 별도 OS 권한이 필요하다.

**Evidence / maturity:** Open-source implementations; early adoption, independent HIL validation required.
